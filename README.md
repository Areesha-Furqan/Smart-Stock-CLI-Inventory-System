🚀 Small project, big lesson: I built an Inventory Management System from scratch.

As a junior backend developer, I wanted to move past tutorials and build something that mirrors a real business function — because every retail app, e-commerce platform, and POS system out there needs inventory logic at its core.

So I built **SmartStock** 📦 — a command-line inventory manager in pure Python (no frameworks, no external libraries) that lets a shop owner:

✅ Add & search products
✅ Track stock levels with automatic low-stock alerts
✅ Sell stock without ever overselling
✅ Restock in seconds
✅ Permanently remove products — with an audit log of what was deleted
✅ Never lose data, thanks to automatic JSON persistence between runs

The part I'm proudest of isn't the menu — it's the defensive programming underneath it: every single user input is wrapped in validation loops, so the program never crashes no matter what someone types. Bad input? It just asks again. Try to sell more stock than exists? It stops you and offers a smarter alternative. Empty inventory? A clean, friendly message instead of a stack trace.

It's a simple project on the surface, but it forced me to think like a backend developer — data modeling, business rules, and error handling — not just "make it run once."
